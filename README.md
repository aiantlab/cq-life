# CQ Life — 双钢路 → 东水门大桥 → 南滨路 v0.2

浏览器端 Three.js 开放世界生活原型。

**切片 1 场景：** 重庆市渝中区大溪沟，捍卫路与双钢路交叉口附近普通住宅小区（钢院 / 双钢路小区，约双钢路 1 号一带）。老旧改造多层：白绿马赛克外立面、中心花园/广场、门禁大门。玩家住在**本小区**，不是南山半山、不是南岸龙门浩开局。

**可玩循环：** 走路 / 开车进出小区 → 回家吃饭、睡觉、换衣 → 门岗外便利店购物 → 日夜与饥饿/精力 → **出小区向南经东水门大桥抵达南滨路滨江段**。

南滨路为原型化干道与临江密度（非 1:1 商场品牌复刻）。解放碑 / 洪崖洞等渝中地标节点仍等 Boss 拍板后再做。

## 本地运行

```bash
npm install
npm run dev
```

打开终端提示的本地地址（默认 `http://localhost:5173`）。桌面 Chrome / Edge。

```bash
npm run build
npm run preview
```

## 操作

| 键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（开车为油门/转向） |
| Shift | 跑步 |
| 鼠标 | 环视（点击画面锁定） |
| E | 互动（进门/吃饭/睡觉/购物） |
| F | 上车 / 下车 |
| Esc | 释放鼠标 |

## 技术

- Vite + TypeScript + Three.js
- `@dimforge/rapier3d-compat`（物理世界已初始化；角色/车本切片用轻量 AABB 碰撞保证可玩帧率）
- 程序化 Canvas 纹理（湿柏油、白绿马赛克、抹灰、草地等），无第三方模型包
